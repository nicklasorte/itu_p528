# itu_p528

MATLAB port of the U.S. reference implementation of Recommendation ITU-R P.528-5, *Propagation curves for aeronautical mobile and radionavigation services using the VHF, UHF and SHF bands*. The model predicts basic transmission loss for air-to-ground and air-to-air paths from 100 MHz to 30 GHz, with terminal heights from 1.5 m to 20 km and time percentages from 1% to 99%.

The port follows the NTIA C++ reference code ([NTIA/p528](https://github.com/NTIA/p528), commit `74870ab`) function by function, and is validated against 800 cases computed with that code.

## Use

```matlab
addpath src
A = p528_rev1(15, 10, 1000, 500, 0, 50)          % 110.0 dB

% Arrays expand; scalars broadcast.
d = [0.5 1 5 20 58];                              % km
A = p528_rev1(d, 10, 121.92, 8160, 1, 50);        % drone at 400 ft, earth station at 10 m

% Full outputs and reference return codes
[A, res, rtn] = p528_rev1(d, 10, 121.92, 8160, 1, 50, 'error_mode', "code");
```

### Inputs

| Input | Units | Range | Description |
| --- | --- | --- | --- |
| `d_km` | km | >= 0 | Great-circle distance between terminals |
| `h_1_m` | m | 1.5-20,000 (warning to 80,000) | Height of the low terminal |
| `h_2_m` | m | 1.5-20,000 (warning to 80,000), >= `h_1_m` | Height of the high terminal |
| `f_mhz` | MHz | 100-30,000 | Frequency |
| `T_pol` | | 0 or 1 | Polarization: 0 horizontal, 1 vertical |
| `p` | % | 1-99 | Time percentage |

Options: `error_mode` (`"error"` raises `p528:invalidInput`, the default; `"code"` returns `NaN` and the reference error code), and `parallel_flag` (1 uses `parfor`).

### Outputs

| Output | Description |
| --- | --- |
| `A_db` | Basic transmission loss, dB |
| `res` | Struct array: `d_km`, `A_db`, `A_fs_db` (free space), `A_a_db` (atmospheric absorption), `theta_h1_rad`, `propagation_mode` (1 line of sight, 2 diffraction, 3 troposcatter), `warnings` (bit flags: 1 no diffraction/troposcatter crossover found, 2 `h_1` above 20 km, 4 `h_2` above 20 km) |
| `rtn` | Reference return codes: 0 success, 11 success with warnings, 1-10 validation errors (see [ERRORS_AND_WARNINGS.md in NTIA/p528](https://github.com/NTIA/p528/blob/master/ERRORS_AND_WARNINGS.md)) |

## Validation

`tests/test_p528_rev1.m` has 12 tests. All pass in MATLAB R2025b, including the parallel check on a 2-worker pool.

| Test | What it checks |
| --- | --- |
| `test_readme_examples` | The four example values in the NTIA README, to 0.1 dB |
| `test_against_cpp_reference` | 800 cases in `tests/reference_ntia_cpp.csv`: README examples, 60 drone-to-earth-station cases (10 m to 121.92 m at 8160 MHz), and 736 seeded random cases. Return codes, propagation modes, and warnings must match; loss, free-space loss, absorption, and distance must agree to 1e-6 dB (largest difference 2.4e-10 dB) |
| `test_transhorizon_reference` | 300 cases in `tests/reference_ntia_cpp_transhorizon.csv` aimed at the diffraction and troposcatter regions near the radio horizon, terminal heights above 20 km (warning codes), equal heights, and a fine time-percentage sweep |
| `test_components_against_cpp` | P.835 atmosphere at 10 heights, P.676 specific attenuation at 5 frequencies, and 5 slant paths (including one below the horizon) against `tests/reference_components_cpp.txt` |
| `test_invalid_inputs` | Every validation error code, and the `p528:invalidInput` error |
| `test_zero_distance_equal_heights` | Zero loss with success, as in the reference |
| `test_free_space_floor`, `test_free_space_formula` | Short line-of-sight paths stay near free space; the free-space formula |
| `test_physical_properties` | Loss increases with distance and doesn't decrease as the time percentage rises |
| `test_variability_helpers` | Inverse normal CCDF against tables, Nakagami-Rice median of zero, inversion of the 99% column |
| `test_unreachable_grazing_point_errors` | The bounded grazing-height search raises `p676:noGrazingPoint` where the C++ hangs |
| `test_parallel_matches_serial` | `parallel_flag = 1` equals the serial result (filtered when no pool is open) |

All reference data come from the NTIA C++ code compiled from commit `74870ab` with `tools/p528_reference_driver.cpp` and `tools/component_reference_driver.cpp`. Input lists are in `tests/reference_cases_input.txt` and `tests/reference_cases_transhorizon_input.txt`.

To regenerate the reference file:

```bash
git clone https://github.com/NTIA/p528
g++ -O2 -std=c++14 -include cmath -include cstring -I p528/include \
    tools/p528_reference_driver.cpp p528/src/p528/*.cpp p528/src/p676/*.cpp p528/src/p835/*.cpp -o p528ref
# Remove __declspec(dllexport) from p528/include/*.h first on non-Windows systems.
./p528ref < cases.txt
```

## Changes from the reference implementation

As the NTIA software release asks, this notice records how this derivative work differs from the original. Changes made November 2026:

1. Translated from C++ to MATLAB, one file per reference source group.
2. The ray trace (`RayTrace.cpp`) is vectorized over atmospheric layers; sums keep the C++ left-to-right order.
3. The two unbounded binary searches on `delta_r` in `LineOfSight.cpp` stop after 2,000 steps and raise `p528:noConvergence`, and the grazing-height search in `SlantPath.cpp` stops after 200 steps and raises `p676:noGrazingPoint`. The C++ loops forever in those cases; the grazing-height hang was reproduced with the reference build for a ray steeper than the horizon dip.
4. Added an array wrapper (`p528_rev1`) with input expansion, an error mode, and an optional `parfor` path.

## Known differences from the Recommendation

These behaviors are in the reference code and are reproduced on purpose so the port matches it. Review them before relying on the affected outputs.

- `NakagamiRice.cpp` interpolates with `NakagamiRiceCurves[d_K - 1][d_p] - 1`, which subtracts 1 dB from a table value where the column index `d_p - 1` appears to be intended. It affects time percentages that fall between table entries when K is between -40 and 20.
- When the transhorizon search finds no crossover, the code returns `CONST_MODE__DIFFRACTION`, whose value equals `CASE_1`, so the model then picks the lower of diffraction and troposcatter loss.
